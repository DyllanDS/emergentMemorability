RANDOM LISTS, BINNED BY NUMBER OF CLOSE NEIGHBORS ON THE LIST
============================================================================================
Lists are drawn at random. Each test item is then binned by how many of the
studied items fall inside its 50 nearest neighbors in the database.
This is the same quantity the designed lists manipulate, occurring here by
chance.

READING THIS
--------------------------------------------------------------------------------------------
  The count of close neighbors is what the designed lists set deliberately
  and what random lists deliver by chance, so the two analyses can be read
  against each other directly.
  Watch corrected recognition against d-prime. Hits and false alarms both
  rise with the count, so their difference moves far less than d-prime does.
