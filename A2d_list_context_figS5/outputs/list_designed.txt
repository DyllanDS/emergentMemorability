THE SAME ITEM ON DESIGNED CROWDED AND UNCROWDED LISTS
========================================================================================
Each critical item appears on every list; only the number of close
neighbors placed alongside it changes. The item is therefore held fixed by
construction, not by statistical control, so nothing about the item can
produce a difference across conditions.

READING THIS
----------------------------------------------------------------------------------------
  Every row is the same set of critical items. If d-prime falls as similar
  items are added, then in the model an item's memorability is a fact about
  the list as much as about the item, which is what the experiments report.
  Compare the size against the random-list version in list_binned.txt: if
  designing the lists produces a far larger effect, then the small effect
  under random sampling is a fact about sampling and not about the model.
